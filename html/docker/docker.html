Основные команды Docker для тестировщика

Работа с контейнерами и образами

  • docker run - запуск контейнера из указанного образа
  • docker ps просмотр списка запущенных контейнеров
  • docker ps -a- просмотр всех контейнеров (включая остановленные)
  • docker images - вывод списка скачанных образов
  • docker stop [ID] - остановка работающего контейнера
